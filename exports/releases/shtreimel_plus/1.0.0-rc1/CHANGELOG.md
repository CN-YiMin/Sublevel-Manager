# Changelog

## 1.0.0 — 2026-11-16

首个正式版。

### 核心

- Sable 已加载物理结构目录
- UUID、名称、维度、世界投影坐标、owner、冻结状态、连接组
- Sable `SubLevelObserver` 事件驱动新增/删除
- 每 20 tick（约 1 Hz）校正位置/owner/冻结
- 未加载 `.slvlr` 结构只在 UI 主动刷新时扫描
- 删除连接链、批量删除、删除前区域文件备份
- 未加载结构逻辑删除 + sector 回收
- Shtreimel owner 读取与冻结/解冻（均为可选）
- Xaero 世界地图菱形叠加层、悬浮提示、右键菜单
- 结构列表、连接组、批量选择、传送、路径点、共享、地图居中、删除
- 工具枪预览（可选，反射按需加载）
- 非 OP 可查看，管理操作要求 OP

### 稳定性

- 无每 tick 子结构遍历
- Shtreimel 类改为反射访问，未安装不会因类加载崩溃
- 服务器停止时清理订阅/缓存/扫描状态
- 未加载扫描 5 秒节流

### 已知限制

- 未加载 region 扫描在服务端线程执行，大型存档可能造成短暂卡顿
- 连接链 `chainId` 每次扫描仍可能产生 O(n²) 级连接链遍历
- 未加载删除依赖 Sable 内部 storage accessor
- 未完成真实客户端/服务端联调
