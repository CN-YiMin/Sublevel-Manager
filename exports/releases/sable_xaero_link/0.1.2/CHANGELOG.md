# Changelog

## 0.1.2 — 2026-11-16

### 变更

- 地图菱形标记放大，并增加深色外框
- 悬停判定范围同步扩大
- 右侧 `S` 按钮放大

### 修复

- 删除主结构后，级联删除的绳索连接子结构会在面板/地图上残留
- 已加载结构消失时自动发送完整目录，清理未加载子结构的旧标记
- 删除已加载主结构时通过 `SubLevelHelper.getConnectedChain` 统一移除整条连接链
