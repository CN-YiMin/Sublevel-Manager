# Changelog

## 0.1.3 — 2026-11-16

### 新增

- 删除后立即刷新目录
- 批量删除：
  - `/sablexaerolink delete <uuid...>`
  - 列表右键勾选 + “批量删除选中”
  - “选中整组”按连接组批量勾选
- 连接组列表：
  - 服务端通过 `SubLevelHelper.getConnectedChain` 计算 `chainId`
  - 客户端列表按 `chainId` 分组，并显示“连接组 … · N 个结构”
- Shtreimel 冻结：
  - 右键“冻结/解冻物理”
  - 列表显示 `[F]`
  - 冻结结构地图标记变为蓝色
- 载具包裹放置者补记：
  - 记录最近一次右键位置
  - 新增且 owner 为空的 Sable 结构，在距离/时间内匹配时自动写入 Shtreimel owner

### 修复

- 删除主结构后，连接子结构的旧标记不会立即消失
- 批量删除只刷新一次，避免每个 UUID 都重扫目录

### 已知限制

- 载具包裹 owner 补记是通用启发式，未针对 HNG 具体物品验证
- 未加载结构仍是逻辑删除 + 区域文件备份
- 未完成真实客户端/服务端联调
